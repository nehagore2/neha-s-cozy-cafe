# Neha's Cozy Cafe ☕

A cozy cafe website built with HTML, CSS, and JavaScript.  
This is a responsive landing page with a menu section for a cafe.

✨ Features
- Responsive Design**: Looks good on mobile, tablet, and desktop
- Menu Section**: Displays cafe items with images
- Modern UI**: Warm, cozy theme for a cafe
- Interactive**: Basic JS for smooth user experience
- Screenshots Folder**: Added for portfolio/email sharing

 🛠️ Tech Stack
- HTML5
- CSS3 
- JavaScript
